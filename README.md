# 💼 JOB HUB

A responsive job portal website built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://alan2006prince-say.github.io/job-hub/

## 📌 About the Project

JOB HUB is a front-end job portal designed to help users explore job opportunities, view job details, save jobs, and track their applications.

The project was created as a portfolio project to practice front-end web development and JavaScript functionality.

## ✨ Features

- 🔐 User Registration and Login
- 🏠 Responsive Home Page
- 📊 User Dashboard
- 🔎 Job Search and Location Search
- 💼 Job Listings
- 📄 Dynamic Job Details
- 📝 Apply for Jobs
- ⭐ Save Jobs
- 🗑️ Remove Saved Jobs
- 📋 Application Tracking
- 🔄 Application Status Updates
- 👤 Profile Management
- 🚪 Logout Functionality
- 📱 Responsive Design
- 💾 LocalStorage Data Management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
- GitHub Pages
